# Tic Tac Toe Game 🎮

A simple and interactive **Tic Tac Toe game** built using HTML, CSS, and JavaScript. This two-player game allows players to take turns marking spaces on a 3×3 grid with **O** and **X**. The game automatically detects the winner or declares a draw when all cells are filled.

## ✨ Features
- 🎯 Interactive 3×3 game board.
- 👥 Two-player gameplay.
- ❌ Players take turns using X and O.
- 🏆 Automatic winner detection.
- 🤝 Draw detection when all cells are filled without a winner.
- 🔄 Reset Game and New Game buttons.
- 🎨 Simple and attractive user interface with hover effects.

## 🛠️ Technologies Used
- **HTML5** – Structures the game board and buttons.
- **CSS3** – Provides styling, layout, colors, and hover effects.
- **JavaScript** – Handles player turns, winning combinations, draw detection, and game resets.

## 📂 Project Structure
- `index1.html` – Main game interface.
- `style1.css` – Styling and layout.
- `script1.js` – Game logic and functionality.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index1.html` in your web browser.
4. Start playing by clicking any cell on the board.

## 🎮 How to Play
1. Player O starts the game.
2. Player X takes the next turn.
3. Players alternate turns by clicking empty cells.
4. The first player to align three matching symbols horizontally, vertically, or diagonally wins.
5. If all nine cells are filled without a winner, the game ends in a draw.
6. Click **Reset Game** or **New Game** to play again.
